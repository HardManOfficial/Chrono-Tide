🏆 设计亮点总结

🎨 一致的视觉语言
从色彩到间距，从圆角到阴影，全项目遵循统一的设计令牌（Design Tokens），确保每个像素都传达相同的品牌质感。
♿ 可访问性考虑
高对比度文本、清晰的焦点状态、足够的点击区域（最小44px）、语义化的颜色使用（不仅依赖颜色传达信息）。
⚡ 性能优化
图片缓存（cacheWidth/Height）、列表虚拟化（GridView.builder）、状态缓存（AutomaticKeepAlive）、防抖搜索（300ms debounce）。
🛡️ 错误处理
优雅的错误状态展示（空状态、错误视图、重试机制）、友好的错误提示文案（避免技术术语）、清晰的操作指引。
🎯 情感化设计
颜文字装饰（´• ω •`）（≧◡≦）、温暖的手写体中文标题字体、柔和的色彩过渡、拟物化的物理感交互。
📱 响应式适配
最小窗口尺寸约束（960×540）、弹性布局（Expanded/Flexible）、自适应文字（AutoSizeText）、动态网格列数。

🔬 深度研究：卡片布局与排序机制

📐 网格布局参数对比 (Grid Layout Comparison)

参数 LibraryPage (游戏库) DiscoverPage (探索页) 差异说明
列数 (crossAxisCount) 4 (硬编码) 4 (硬编码) ⚠️ 均为固定值，无响应式
垂直间距 (mainAxisSpacing) 27px 24px 库页多 3px（可能为拖拽预留）
水平间距 (crossAxisSpacing) 24px 24px ✅ 完全一致
宽高比 (childAspectRatio) 2 / 3 (0.667) 2 / 3 (0.667) ✅ 完全一致（竖向卡片）
网格内边距 EdgeInsets.fromLTRB(8, 8, 8, 4) 无额外 padding 库页有 8px 微调边距
缓存策略 cacheExtent: 400 默认值 库页优化了滚动性能
⚠️ 关键问题：两个页面都使用 SliverGridDelegateWithFixedCrossAxisCount，列数写死为 4
这意味着在窗口缩放或不同分辨率下，卡片大小会改变但列数不变

📊 卡片排序逻辑深度解析

📚 LibraryPage 排序逻辑

排序类型：用户自定义拖拽排序

数据持久化：

Key: 'library_game_order'
Type: SharedPreferences (StringList)
Value: [游戏标题1, 游戏标题2, ...]

排序算法：

  1. 从 SharedPreferences 读取保存的顺序列表
  2. 构建 orderMap<String, int> 映射表
  3. 对当前游戏列表进行排序： 
    indexA = orderMap[a.title] ?? 999999;
indexB = orderMap[b.title] ?? 999999;
return indexA.compareTo(indexB);
  4. 新添加的游戏自动排到末尾（index=999999）

交互方式：

  • ✅ 长按 300ms 触发拖拽模式
  • ✅ 拖拽时显示幽灵卡片（原位置30%透明度）
  • ✅ 目标位置显示蓝色高亮边框
  • ✅ 释放后立即保存新顺序到本地
  • ✅ 拖拽动画：liftAnimation (300ms easeOutCubic)

🔍 DiscoverPage 排序逻辑

排序类型：API 返回顺序 + 过滤器

数据获取：

分页加载: page=1, perPage=100
循环请求直到 hasMore=false
全部加载到 _allGames 列表

过滤流程：

  1. 获取搜索关键词 → 提取第一个词作为名称搜索
  2. 剩余词作为标签搜索（支持逗号/空格分隔）
  3. 合并选中的标签 + 搜索的标签
  4. 遍历 _allGames 进行过滤：
    • • 名称包含关键词（不区分大小写）
    • • 标签包含所有选中的标签（AND 逻辑）
  5. 结果存入 _displayGames

❌ 缺失功能：

  • ❌ 无排序选项（按时间/名称/大小等）
  • ❌ 无升序/降序切换
  • ❌ 无拖拽排序功能
  • ❌ 完全依赖 API 默认顺序

⚠️ UI/UX 问题诊断与优化建议

🔴
严重问题 #1: 缺少响应式网格
问题描述：
LibraryPage 和 DiscoverPage 的网格列数均硬编码为 crossAxisCount: 4

影响范围：
• 窗口缩小时卡片过小，内容难以阅读
• 大屏幕显示器上空间浪费
• 不同分辨率设备体验不一致

代码位置：
• library_page.dart:501
• discover_page.dart:569-570

优化建议：
使用 SliverGridDelegateWithMaxCrossAxisExtent 或基于 MediaQuery 动态计算列数：
// 方案A: 最大宽度自适应
SliverGridDelegateWithMaxCrossAxisExtent(
  maxCrossAxisExtent: 280,  // 卡片最大宽度
  mainAxisSpacing: 24,

新游戏不在 orderMap 中 → fallback index = 999999 → 排在所有已知游戏之后

修复方案：

?? 999999?? -1新游戏排到最前面 ✓

     ..lineTo(0, height)

# 错误描述 正确做法 严重度
1 硬编码 Color(0xFF...) 使用 AppColors.xxx 🔴 致命
2 const 含 AppColors 的表达式 移除 const 关键字 🟠 严重
3 用 background 作页面容器背景 改用 pageBackground 🟠 严重
4 自定义组件未处理主题切换 使用 AppColors.of(context) 🟠 严重
5 关闭按钮尺寸/圆角不一致 统一 32×32px, borderRadius=5px 🔵 中等
6 SVG 图标未设置 colorFilter 添加 colorFilter: ColorFilter.mode(#A08264) 🔵 中等
7 阴影参数偏离设计规范 统一 offset=(2,3), blurRadius=0 🟢 轻微
8 Grid crossAxisCount 写死为 4 考虑响应式或保持一致性 🟢 轻微
