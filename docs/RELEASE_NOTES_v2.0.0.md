### 系统要求

- Windows 10 / 11（64 位）
- 无需额外安装运行时，安装包已内置全部依赖
- 元数据抓取需联网；国内访问部分海外数据源建议配置代理

安装包兼作更新包，直接运行即可完成升级。升级过程会清理旧版本文件，但**不会删除 `Games/` 目录**，游戏数据完全安全。

## ✨ 新增

- **MIX 智能整合源** — 并发抓取 VNDB / Hikarinagi / KunGal / Steam / 月幕 五平台，按字段优先级整合结果
- **多任务串行安装队列** — 解除仅当任务限制，支持多个游戏下载任务，失败不阻塞，自动推进
- **游戏系列功能** — 详情页系列横条 + 完整系列树弹层，支持主线 / 分支 / 合集三种模式
- **快捷自定义窗口** — Alt/中键拖拽缩放、按 PID 静音、长按中键 1.2s 临时挂起
- **收藏夹** — 支持新建收藏夹，分类整理自己的游戏
- **智能导入重构** — 五模块流水线 + 五阶段共享扫描管线，去重彻底

## 🔧 优化

- 网格卡片间距 40→24px，卡片等比变大
- 探索页顶栏改 Stack 悬浮，卡片滚动更顺滑
- 库页**左键单击**直接开详情（与触摸 / 右键菜单共用入口）
- 标题自适应：长标题自动换行，不再缩成 10/11px
- 元数据抓取支持副标题兜底（主标题失败自动用副标题重试）
- 详情页 UI 全面升级：标签 / 简介自适应 · 截图弹性 · 系列框轻量化
- 主页自适应修复：窗口挤压时标题、封面、统计表全部贴边
- 侧边栏打磨：主页按钮扁条化、移除底部网络指示器
- 各平台元数据抓取独立运行，可与 MIX 共存

## 🐛 修复

- 库页顶栏随主题自动适配（不再变黑色半透明）
- 标题保存「假成功」问题（标题锁 / 内存覆盖双根因）
- 修复截图无法编辑的问题，恢复编辑能力（支持增删本地截图，6 张上限）
- 编辑态截图无法横滚（支持滚轮 / 拖拽 / 箭头按钮）
- 副标题搜索失效（三处隐藏 bug 全部修复）
- 系列内循环跳转（导航栈去重截断 + 面包屑）
- 批量拖拽归类只处理 1 张（现已联动选中集合）
- 智能导入重复识别（启动器合集、命名取错目录层级）

## ⚠️ 已知问题

- 快捷自定义窗口的中键手势与部分使用鼠标中键操作视角的游戏（如 FPS）存在冲突，可在「设置 → 外观与通知」中一键关闭该功能。
