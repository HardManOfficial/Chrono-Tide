# 主页"近7日游玩折线统计表"升级方案（v1.0）

> 改造目标：在**严格保留现有 UI 风格**的前提下，将"近7日折线"升级为支持**历史数据回溯**的"阅历"系统。**不重构、不换色、不换字体**，新增能力以**等比放大折线图**与**等比缩小功能按钮**的方式嵌入。

---

## 0. 设计原则（约束清单）

| 原则 | 落地策略 |
|---|---|
| ① 维持整体 UI 框架 / 色彩 / 字体 / 交互不变 | 沿用 [play_stats_panel.dart](file:///d:/CTLIB/lib/widgets/play_stats_panel.dart) 现有 `AppColors`、`fl_chart` 配色、圆角 6、阴影 (1,2,6) 模糊 0.06 透明度、Inter 字体、11pt 标题、8~9pt 副文、14pt 图标 |
| ② 折线表等比例放大，腾出空间 | 容器 **280×168 → 380×232**（等比缩放 1.36×），折线图本体相应放大 |
| ③ 新增功能按钮缩小并协调 | 时间段切换使用 18~20px 微胶囊按钮（与现有筛选 `_HoverChip` 同款 11pt 字号、12px 圆角）；工具图标 14pt |
| ④ 不大规模重构 | 仅在 `play_stats_panel.dart` 内部改造，外部调用方（`home_page.dart` 的 `Positioned` 定位）零改动 |

## 4. 时间段切换的"免破坏"实现

由于升级版**不引入新数据表**（沿用各游戏 `daily_play_log`），仅做**前端聚合切换**：

```
[7日]  →  直接读现有 7 日 daily_play_log  → 现有图表重绘
[30日] →  一次性聚合 30 日日志           → 折线点变密（仍用 fl_chart）
[90日] →  7 日一聚合（共 ~13 点）        → X 轴标签显示周
[全部] →  自然月聚合                      → X 轴标签显示月
[📅]   →  弹出双日历选择器               → 任意区间
```

**关键约束**：所有数据从 `LocalGameRegistry` + `game.json` 现有 `daily_play_log` 字段读取，**不写新数据库**。粒度切换仅在前端 `setState` 内存内完成。

## 9. 风险与回滚

| 风险 | 缓解 |
|---|---|
| 380×232 在小屏幕挤压 | `home_page.dart` 的 `Stack` 已 `Positioned` 锚定右下，不影响；如挤压则降到 340×210 备用尺寸 |
| 时段切换聚合时数据稀疏 | 跨度 > 90 日自动按周/月聚合，避免 X 轴点过密 |
| 实时流 + 历史聚合两条逻辑混乱 | 维持单一 `setState` 通道，时段变化仅切数据源，行为类似原版的"切换游戏触发重载" |
| 回滚 | 8 处改动均在 `play_stats_panel.dart` 内部，git revert 单文件即可 |
