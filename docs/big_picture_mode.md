# Chrono Tide 大屏模式 (BPM) 用户手册

> 版本：v1.3  ·  适用于 CTLIB v0.8+  ·  适用于 Windows 10/11

## 一、什么是大屏模式

大屏模式（Big Picture Mode，简称 BPM）是 Chrono Tide 为**客厅串流**与**触屏远距操作**场景设计的另一种界面。它将所有控件放大 1.6 倍，提供更适合远距离观看的布局，同时支持键盘、鼠标、触屏三种输入方式。

> **v1.2 变更提示**：完成 BPM 全页面 UI 系统优化——首页 / 库页 / 探索页焦点滚动联动与布局容错修复；添加页引入 BPM 专属包装组件（`BpmFileDropZone` / `BpmMetadataSection`）替换桌面组件，统一视觉与键盘焦点；详情页修复无 exe 死胡同（就地打开启动管理器）、启动按钮窄屏溢出、焦点系统与字号规范。详见第九章版本历史。

### 适用场景

| 场景 | 推荐度 |
|---|---|
| 接电视/投影，远距操作 | ⭐⭐⭐⭐⭐ |
| 串流到平板/手机远端游玩 | ⭐⭐⭐⭐⭐ |
| 主显示器键盘+鼠标常规使用 | ⭐⭐（建议使用桌面模式） |

## 二、进入与退出

### 进入 BPM

**方式 1：主页列表头部图标按钮**
在桌面模式主页（首页），点击页面列表头部右上角的「大屏模式」小图标按钮（24×24，fullscreen 图标，悬停显示「大屏模式 (F11)」提示）。该按钮位于头部空白处，不影响原 UI 布局。

**方式 2：用户窗口右上角图标按钮**
点击桌面模式侧边栏底部的用户头像打开用户窗口，点击窗口右上角的小图标按钮（fullscreen 图标，与关闭按钮并列，悬停显示「大屏模式 (F11)」提示）。该按钮位于头部空白处，不影响底部原「个人设置」「退出登录」两按钮布局。

**方式 3：键盘快捷键**
按下 `F11` 键，瞬间切换到 BPM。

进入后窗口会自动切换为**全屏模式**，覆盖整个屏幕。

### 退出 BPM

**方式 1：导航栏退出按钮**
点击 BPM 左侧导航栏最底部的「退出」按钮（图标为四角向内箭头）。

**方式 2：键盘快捷键**
- 在首页/库页/探索页/添加页：按 `Esc` 退出 BPM
- 在详情页：按 `Esc` 先返回库页，再按 `Esc` 退出 BPM
- 任意位置：按 `F11` 切换（与进入是同一键）

退出后窗口恢复为窗口模式，回到桌面模式上次停留的页面。

## 三、四个页面功能

BPM 左侧导航栏有 5 个按钮（4 个页面 + 1 个退出）。从上到下：**首页 → 游戏库 → 探索 → 添加 → （底部）退出**。文字与桌面模式保持一致（v1.0 的「发现」「入库」已分别改回「探索」「添加」）。

### 1. 首页 (Home)

**v1.3 Ubiquity 风格全屏沉浸式布局**，参考 WePlayNight 的 Ubiquity 主题重写：

**5 层叠加结构**：
- **Layer 0 全屏背景**：当前选中游戏的封面以 `BoxFit.cover` 直接铺满整个内容区（无 `BackdropFilter` 模糊，避免影响左侧导航栏与窗口标题栏）
- **Layer 1 渐变遮罩**：三段式纵向渐变（顶部 0.55 → 中部 0.15 → 底部 0.85），保证文字在任意背景上可读
- **Layer 2 左中信息层**（最大宽 720px）：
  - 标签行：游戏标签（最多 5 个，半透明胶囊样式）
  - 大标题：游戏名（ZhiMangXing 字体，48px，白色 + 黑色阴影）
  - 元数据行：状态徽章 · 开发商 · 游玩时长 · 收藏标记
  - 简介：最多 3 行
  - **启动游戏**按钮（强调色填充）+ **查看详情**按钮（玻璃拟态半透明）
- **Layer 3 顶部右侧筛选 chips**：5 个状态筛选，半透明容器包裹
- **Layer 4 底部水平封面轮播**：140×200 竖版封面卡片（接近 GAL 标准封面比例），选中卡片高亮边框 + 缩放 1.08 + 强调色辉光，未选中卡片暗化遮罩

**交互**：
- 方向键 ←→ 或鼠标点击底部轮播卡片切换游戏，背景与信息层同步更新
- 双击底部卡片或回车键启动游戏
- 长按卡片弹出动作表（启动 / 标记 / 启动管理 / 删除）
- 点击「查看详情」进入详情页

**焦点策略**（v1.3 改进）：首项轮播卡片负责 autofocus，启动按钮不抢焦点，让用户先浏览选定游戏再启动，符合 Ubiquity 交互范式。

### 2. 游戏库 (Library)

完整本地游戏库浏览页，支持：

- **搜索框**：按游戏标题模糊搜索
- **排序下拉**：按名称 / 入库时间 / 最近游玩时间排序
- **16:9 卡片网格**：每个卡片显示封面、标题、状态徽章、收藏标记
- **空库引导**：当本地无任何游戏时显示「前往添加或探索页」提示

### 3. 探索 (Discover)

可下载游戏列表，与桌面模式探索页数据源一致：

- 顶部展示游戏总数与「刷新」按钮
- **页面加载即并发获取总数与第一页数据**（v1.1 修复），无需手动刷新即可显示总数
- 网格展示可下载游戏（封面 + 标题 + 开发者 + 已入库徽章）
- **方向键移动焦点时自动滚动让卡片可见**（v1.1 修复）：`FocusTraversalGroup(policy: FocusGridPolicy())` 包裹网格，每张卡片 `Focus(onFocusChange)` 联动 `Scrollable.ensureVisible(alignment: 0.5)`
- 滚动到底部自动加载下一页
- 点击卡片弹出**详情对话框**（宽 880，最大高度为屏高 - 200，**支持内部滚动**），含「下载」按钮
- 下载流程通过桌面模式的 `InstallCenterPage` 处理（用户可切回桌面查看进度）

### 4. 添加 (Join)

本地游戏入库页，与桌面模式入库流程共享 `JoinController`：

- **拖拽导入**：将本地压缩包/文件夹拖入虚线框（v1.2 起改用 BPM 专属 `BpmFileDropZone`，支持键盘焦点导航与 BPM 视觉规范）
- **手动选择**：点击「选择文件」按钮浏览
- **元数据编辑板块**（v1.1 恢复，v1.2 BPM 包装化）：
  - 游戏名称输入框
  - **一键抓取**按钮：根据游戏名调用 VNDB / Bangumi / Steam / 月幕 GAL 等数据源
  - 抓取结果展示（v1.2 起改用 BPM 专属 `BpmMetadataSection`，统一大字号与 BPM 配色；卡片显示平台徽章 / 平台 ID / 标题 / 发售日，点击选中）
  - 标签 / 开发者 / 简介输入框
- 与桌面模式入库流程一致：可修改、填写、抓取、导入游戏数据

### 5. 退出 BPM

最底部按钮，等价于 `Esc` 退出 BPM。

## 四、键盘快捷键速查

| 键 | 行为 | 适用位置 |
|---|---|---|
| `F11` | 切换 BPM（进入/退出） | 任意位置 |
| `Esc` | 详情页返回 / 否则退出 BPM | 任意位置 |
| `Ctrl + F` | 聚焦当前页搜索框 | 仅游戏库页生效 |
| `↑ ↓ ← →` | 在卡片网格中按方向移动焦点 | 游戏库 / 探索页 |
| `Tab` | 在导航栏与内容区之间切换焦点域 | 任意位置 |
| `Shift + Tab` | 反向切换焦点域 | 任意位置 |
| `Enter` / `Space` | 激活当前焦点项（等价于点击） | 任意可激活项 |

### 焦点导航说明

- **不循环**：方向键到达边缘时焦点不移动，与桌面 ListView 行为一致。
- **Tab 跳域**：`Tab` 在「导航栏」与「内容区」两个焦点域之间切换，避免方向键意外跳到导航栏。
- **Enter 激活**：当前焦点项有蓝色辉光边框，按 `Enter` / `Space` 即可激活（启动游戏 / 打开详情 / 切换页面）。

## 五、游戏卡片交互

### 单击

打开游戏**详情页**，展示完整元数据（封面、描述、标签、游玩状态、标记、启动次数等）。

### 双击

**直接启动游戏**（跳过详情页）。若未选择启动 exe，会提示「请先在桌面模式选择启动程序」。

### 长按

弹出**动作表**（底部弹出），含 4 个操作：

| 操作 | 说明 |
|---|---|
| 启动游戏 | 等价于双击 |
| 切换标记 | 在 收藏 ⇄ 星标 ⇄ 无 之间循环 |
| 启动管理 | 打开启动程序选择对话框（选择游戏主 exe） |
| 删除游戏 | 移出本地库（不会删除游戏文件本身，仅移除注册） |

## 六、详情页

点击游戏卡片进入详情页，包含：

- 顶部应用栏：返回按钮 + 页面标题「详情」（v1.2：标题改为「详情」避免与左面板大标题重复；返回按钮接管初始焦点）
- 左面板（40%）：大封面 + 游戏标题 + 开发者 + 标签 + 启动按钮组
- 右面板（60%）：截图轮播 + 简介 + 元数据网格（游玩状态 / 游玩时长 / 安装时间 / 最后游玩）
- 操作区（v1.2：`Wrap` 布局兜底窄屏换行；启动按钮改用 `ConstrainedBox(minWidth: 280)` 允许窄屏收缩）：
  - **开始游戏**（主按钮，最小宽度 280，高 72）
  - **启动管理**（次要按钮，打开启动程序选择对话框）

**未配置启动程序时**（v1.2 修复）：点击「开始游戏」不再弹 SnackBar 让用户切回桌面模式，而是**就地打开启动管理器**引导用户选择 exe，选择后自动持久化并提示「已更新启动程序」。

详情页内可按 `Esc` 或点击左上角「返回」按钮回到原页面。

## 七、与桌面模式的数据互通

BPM 与桌面模式共享所有本地数据，**任何模式下的操作都会即时同步到另一模式**：

| 数据 | 同步机制 |
|---|---|
| 本地游戏库 | 共享 `LocalGameRegistry.instance` 单例 ChangeNotifier |
| 游戏标记 / 状态 | 共享 `game.json` 磁盘存储 |
| 启动 exe 选择 | 共享 `GameConfigManager` + `SharedPreferences` |
| 入库流程 | 共享 `JoinController` |
| 下载流程 | 共享 `GlobalInstallCenter` |
| 主题 / 配色 | 共享 `AppThemeManager` 6 主题单例 |

### 切换主题

BPM 内切换主题的方式：

- 退出 BPM → 在桌面模式侧边栏底部点击「设置」按钮 → 主题
- 或直接在 BPM 内调用 `AppThemeManager`（BPM 监听主题变化会自动重建 UI）

未来版本将在 BPM 设置入口直接提供主题切换。

## 八、常见问题

### Q1: 进入 BPM 后窗口没有全屏？

**A**: 检查 Windows 显示设置中的缩放比例。BPM 调用 `windowManager.setFullScreen(true)`，部分显卡驱动会拦截。建议在 NVIDIA/AMD 控制面板中将 Chrono Tide 设为「全屏模式」。

### Q2: BPM 内键盘导航失灵？

**A**: 确认焦点在 BPM 内（点击任意卡片一次即可获取焦点）。若焦点跳出窗口（如切到其他应用），按 `Tab` 一次回到 BPM。

### Q3: 串流到平板后触屏点击不准？

**A**: BPM 卡片有 1.05x 焦点缩放，触屏点击时建议先点一下让卡片获取焦点，再点中央区域。串流软件（如 Moonlight/Steam Link）的客户端触摸映射可能影响精度，建议在串流客户端开启「触屏作为触控板」模式。

### Q4: 双击启动游戏没反应？

**A**: BPM 启动走 `GameLaunchService.instance`，与桌面模式一致。若未选择启动 exe，BPM 会**就地打开启动管理器**（v1.2 修复，不再要求切回桌面模式）引导你选择游戏主 exe，选择后自动持久化。也可主动通过：

1. 进入游戏详情页 → 点击「启动管理」按钮
2. 或在游戏卡片上长按 → 动作表 → 启动管理

### Q5: BPM 模式卡顿？

**A**: BPM 已对每张卡片做 `RepaintBoundary` 隔离，焦点动画不会触发整网格重绘。若仍卡顿：

- 检查本地游戏库数量（>500 时建议关闭背景图）
- 检查主题背景图分辨率（建议 ≤ 1920x1080）
- 关闭其他占用 GPU 的应用
