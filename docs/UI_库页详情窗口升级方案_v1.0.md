# Chrono Tide 库页详情窗口 UI 升级方案

> **版本**: v2.0
> **日期**: 2026-08-21
> **适用范围**: `lib/widgets/game_detail_dialog.dart` 中**右下侧数据板块下方的标签栏 / 简介 / 截图区**
> **设计参考图**: 用户最终手绘示意图（v2.0）+ 原始 Figma 节点 `https://www.figma.com/design/QjW9iC2pEpF1NSc1tgzhv5/CT?node-id=769-103&m=dev`
> **核心原则**: **极小范围升级**——只改标签栏 / 简介 / 截图三块，**其他部分（封面、整体窗口风格、右上数据板块、启动游戏 / 打开目录 / 编辑按钮）一律保持现状不动**

---

## 一、执行摘要

本次升级**只针对** `GameDetailDialog` 窗口内**右侧数据板块下方的三块内容**：

1. **标签栏**：从原 Wrap 圆角 3px 限 5 个 → 改为**方框带 5-8px 圆角，单行排列**（不限数量，超出处理待 ⑤ 拍板）
2. **简介**：从固定 2 行 39 高 → 改为**两列布局的左侧**，文字自然换行，完整显示（无截断、无省略号）
3. **截图预览区**：从横向 carousel → 改为**两列布局的右侧**，截图**按比例缩小**显示，新增**双击放大**与**悬停放大镜**交互

**保持不动**：
- 左侧封面图
- 整体窗口尺寸 / 圆角 / 边框 / 阴影
- 右上标题 / 关闭按钮
- 右上半外层卡（来源/安装日期/目录/占用空间/会社/启动信息/游玩中）
- 左下「启动游戏 ▾」「打开目录」「编辑」三按钮
- 编辑态、元数据抓取、换目录等功能
- 启动安全（120s + 代际计数 + foreground hook）
- 6 主题令牌系统

### 2.2 三块改造区详细规格

#### ① 标签栏（`tags_row`）

| 维度 | 当前 | 目标 |
|---|---|---|
| 布局 | `Wrap(spacing 6, runSpacing 4)`，多行 | **单行**（超出处理见 ⑤ 决策） |
| 形状 | 圆角 3px 小方块 chip | **方框带 5-8px 圆角**（方框样式） |
| 边框 | 无 | 1px `AppColors.border` |
| 背景 | 透明 / 浅色 | 透明（仅边框） |
| 数量限制 | 最多 5 个 + "+N" 折叠 | **不限**（超出处理见 ⑤ 决策） |
| 字体 | 12 medium | 12 medium（不变） |
| 颜色 | secondaryText | secondaryText（不变） |

#### ② 简介（`description_block`）

| 维度 | 当前 | 目标 |
|---|---|---|
| 位置 | 标签下方独立一行 | **2 列布局的左侧**（与截图预览区并排） |
| 高度 | 固定 2 行 39 高 | **动态高度**，文字自然换行 |
| 截断 | 2 行 `TextOverflow.ellipsis` | **不截断，文字自然完整显示**（设计图里的「...」只是占位示意，不是真省略号） |
| 字体 | 12 regular | 12 regular（不变） |
| 颜色 | primaryText | primaryText（不变） |

**「文字占位」示意（设计图里的"..."是占位，不是真省略号）**：
```
在游戏库页面中，我们可以看到当前游戏的所有标签、简介和截图预览区域。  
在这个新版本中，我们对这些区域进行了重新设计，让 UI 看起来更加...
                                          ↑ 此处「...」= 设计图占位，不是真截断
```

#### ③ 截图预览区（`screenshots_panel`）

| 维度 | 当前 | 目标 |
|---|---|---|
| 位置 | 简介下方独立一行 | **2 列布局的右侧**（与简介并排） |
| 布局 | `ScreenshotsCarousel` 横向滚动 | **静态网格**（待 ⑦ 拍板：1 大 + 多小 / 2×2 网格 / 其他） |
| 缩放 | 原图比例，可能裁切 | **按比例缩小**（`BoxFit.contain`，不裁切） |
| 占位 | carousel 空态 | **"暂无截图（虚线占位）"**（参考图） |
| 交互 1 | 点击大图 → 弹原图 | **双击截图 → 弹原图放大视图**（沿用现有大图查看或新增 lightbox） |
| 交互 2 | 无 | **悬停截图 → 鼠标变放大镜 + 轻微放大**（1.02-1.05x） |

## 七、风险与回退

| 风险 | 等级 | 缓解 |
|---|---|---|
| 标签溢出处理不当 | 中 | 默认横向滚动，5.1 手测验证 |
| 简介动态高度导致右侧截图区高度跳动 | 中 | 截图区用 `ConstrainedBox(minHeight: 120)` 锁定最小高度，或左右两列同高 |
| 截图按比例缩小后太小看不清 | 低 | 默认 1.03x 悬停放大，5.1 手测验证 |
| 悬停缩放与触摸手势冲突 | **高** | 必须用 `MouseRegion`（鼠标专用），不能用 `Listener` 改触摸行为；测试触摸流程不破坏 |
| 双击放大与悬停缩放时间窗冲突 | 低 | 双击 < 200ms 完成，悬停动画启动延迟设 200ms |
| 6 主题下标签边框颜色不一致 | 低 | 用 `AppColors.border` 令牌 |
| 改造引入其他区域回归 | 中 | 仅修改 3 个区块的代码，其他代码完全不动；5.1 回归手测 |
| lightbox 实现与 carousel 不一致 | 低 | 优先复用现有大图查看逻辑 |

**回退方案**：阶段 0 已备份 `lib_backup_20260821/`，任意阶段回退时一键恢复。
