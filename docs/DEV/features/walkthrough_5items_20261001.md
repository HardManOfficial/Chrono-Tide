## ② 【发布】三步流（新建投稿，5 分钟）

- **入口**：登录账号 → 详情页或探索大厅 →「分享」。
- **操作**：任选一个游戏 → 填标题 / 链接 / 资源类型 → 下一步预览 → 提交。
- **预期**：提交成功提示**「待审核」**；【我的】投稿列表出现该条、状态 = 待审核。
- 📌 提交完**告诉我一声**，我用后台把这条投稿「驳回」→ 你接着做 ③。

## ③ 驳回投稿重提（A 方案状态机，2 分钟）

- **前置**：我已在后台把你在 ② 发的投稿置为「已驳回」。
- **入口**：【我的】投稿列表。
- **操作**：找到那条已驳回投稿 → 编辑（改不改内容都行）→ 重新提交。
- **预期**：重提成功、状态变回**「待审核」**。（后台规则只放行「已驳回 → 待审核」
  这一条路，其他任何状态跳变都被服务端锁死——这就是 A 方案。）
- 📌 重提完**再告诉我一声**，我把这条投稿「过审」成「已发布」→ 你接着做 ④⑤。
