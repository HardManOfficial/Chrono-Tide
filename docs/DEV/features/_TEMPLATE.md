# 功能档案模板

> **用途**：一个功能一份档案，记录它的**目标、设计思路、历史决策、当前进度**。
> 这是解决「AI 不知道之前开发目标和思路，每次从零开始」的核心手段。
>
> **使用方法**：复制本文件为 `docs/DEV/features/<功能名>.md`，填写后删掉本说明块。
> **维护时机**：开发该功能时建立；每次改动后必须回写「当前进度 / 已知问题 / 待办」。
