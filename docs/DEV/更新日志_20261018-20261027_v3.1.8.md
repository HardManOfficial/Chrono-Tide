## [v3.1.8] — 2026-10-27

> **v3.1.8** 是 3.1 线上的**功能性大版本**，六条主线：**本地优先账号与头像池**、**启动兼容性自动配置与提权**、**启动程序智能推荐**、**探索 / 详情联动（KUNGAL 直达、实时刷新）**、**小窗口与大厅布局治理**、**会社 / 标签数据扩批**。
>
> 规模：**20 次提交、139 个文件（+31,065 / −1,045）**，另有 BPM 主页 hero 改版、KUNGAL 联动、探索库实时刷新等收尾改动随本版构建一并进入。
>
> 一句话：这一版主要解决「**小窗口能不能用**」「**启动游戏这一步别再出错**」「**新用户第一眼别再被登录窗挡住**」三件事，顺带把探索库的数据覆盖从六成拉到九成八。

**升级说明**

- 安装包兼作更新包，直接覆盖安装即可升级，**不会删除 `Games/` 目录**，游戏数据完全安全。
- **账号**：仅「全新安装」首启动会直接进主界面（不再弹登录窗）；已有在线账号 / 已有本地身份的用户不受影响，不会丢资料。

### ✨ 新增

- **本地优先账号 + 系统头像池** — 新用户不再被登录窗挡脸：
  - 全新安装首启动**直接进入主界面**，自动创建本地身份「萌萌团」并从 **34 张系统头像**中随机取一张
  - 头像修改口收敛为**两处**：设置 → 个人资料（34 张网格自选 + 随机重抽）、注册表单昵称行
  - 换头像后悬浮按钮 / 大屏顶栏 / 用户卡片 / 设置页**四处即时同步**，无需重启
  - 未登录点击云端功能（下载 / 点赞 / 上传 / 分享 / 文档发布）统一提示「该功能需要账号 · 本地管理功能不受影响」
  - 登录时**不会覆盖**云端已有头像；已登录用户看他人分享的头像是实时的
- **启动兼容性自动配置 + 超分 / 转区提权** — 让「启动游戏」这一步在各种环境下都能跑起来：
  - 启动前自动为游戏 exe 写入 Windows 兼容性属性（Win8 兼容 / 禁用全屏优化 / 替代高 DPI 缩放），**除「以管理员身份运行」外全静默**；可在「启动管理」与「设置 → 游戏与启动」总开关（默认开启）
  - **超分（Magpie）与转区（LEProc）本身以管理员权限运行**，且超分跟随游戏一起提权（否则捕获不到提权窗口、超分静默失效）
  - 新增「以管理员身份运行」开关（启动程序选择器 / 启动管理 / 设置三处）
  - **启动链路四合一**：普通 / 超分 / 转区 / 托盘四个入口统一到同一个执行器，权限裁决不再各写一套；UNC 工作目录、740 权限拒绝等复杂场景各有明确通道
  - 「管理员权限需要重启」一生一次提示，可一键延迟重启（不会撞单实例锁）
- **启动程序智能推荐** — 选择启动程序时自动分类并推荐：
  - 无关程序（卸载器 / 运行库 / 安装包）标灰「**工具**」，游戏相关程序区分 **HD / 原版 / 魔改 / 汉化** 等版本
  - **汉化版**优先打琥珀「**★ 推荐**」角标，并在选择器顶部提示「已标出 N 个」
  - 只标角标，**不重排、不隐藏、不改默认选中**（尊重你的手动选择）
  - 推荐项全部过 PE 头校验，保证是「点得动」的有效程序
- **详情页一键跳 KUNGAL** — 探索详情页头部（「喜欢」与「反馈」之间）新增外链图标，一键打开该作品在 KUNGAL 的站内页；已收录直达作品页，未收录落到站内搜索页；**进入详情首帧即出现**，不用等解析
- **社群入口 + 官方链接直达** — 用户资料面板「为小站充电」新增【加入群聊】（QQ 群二维码卡片 + 一键拉起邀请页）；设置 → 关于应用左下角、探索大厅「文档与趣味 → 介绍」各新增 **GitHub 仓库 / 项目官网** 直达入口
- **大屏主页 hero 改版 + 背景双卡 + 主页隐藏**：
  - 主页移除「继续游戏」栏；标题放大至 72px（标题图 ≤620×144）；**会社与发售年份一行、标签改小方框分行展示**；主页不再展示副标题
  - 背景管理新增「**横幅卡（16:9）/ 竖版封面卡**」并排可选（此前只能看到竖版，无法判断自己有没有横版图），当前生效图有明确标注
  - 大屏详情「⋯」菜单新增「从主页隐藏卡片 / 显示到主页」
- **删除游戏可选移入回收站（本地导入游戏）** — 勾选「同时删除本地游戏文件」终于真正生效：
  - 本地导入游戏改为**移入回收站（可还原）**，不再是一句空承诺
  - 确认框如实区分三种结果：应用内永久删除 / **移入回收站** / 受保护不删；可回收时提示「回收站仍占空间，清空后才彻底释放」
  - 安全护栏：网络位置、盘根、应用目录及其祖先、系统目录、用户主目录等一律拒绝删除并说明原因
  - 批量删除先统计「N 个将移入回收站、M 个受保护不会被删除」；每次操作写审计日志
- **会社词典 / 标签词表扩批** — 分类匣与标签体系的数据底座大幅补全：

### 🔧 优化

- **侧边栏等比缩放** — 小窗口不再「添加只剩一截图标、主页被顶出窗口」：卡片高宽比恒定 144:175，图标 / 字号 / 间距 / 徽章同比缩放；960×540 ~ 2560×1440 共十档实测**零溢出、零裁切**，跨尺寸视觉统一
- **内容区小窗自适应** — 主页窄窗改为「详情独占 + 34px 游戏库竖条」（点一下列表独占全宽），正文由 7.2px 提升到 **11.7px**（960×600 故障档）；探索大厅不再把面板按 flex 一起压扁
- **探索大厅整屏布局重构** — 默认 1280×720 下六块面板**全部整份落在框内、零滚动零裁切**：
  - 站点 / 系列卡宽由可用宽反推，恒等式保证「第 N+1 张正好从边界开始」，**永不露半张卡**
  - 相关话题行高吃掉余量，**不再出现底部整行黑留白**
  - 文档面板高度让位给上方两块，正文视口 122.5 → 169.5，零滚动
  - **窗口四个尺寸数合一**：设计 = 默认 = 最小 = 恢复下限 = **1280×720**（此前 960×540 / 1120×620 / 1280×720 三个数互不相干，导致「能拖小、下次启动又被强行放大」）
- **窗口几何恢复下限** — 历史几何低于 **1120×620** 时回默认尺寸、位置仍按原相对中心恢复；修好「打包更新后窗口变小、装多少次新版本都不自愈」
- **OpenList 升级对齐** — 修好「更新完仍然取不到下载链接」：判据由「openlist.exe 是否存在」改为「已对接 **或** 存在五条安装痕迹」，缺组件时现场补齐；组件包先于配置包应用（否则每次启动重复下载 53 MB）
- **探索库实时刷新** — 进程不退出也能看到新作品：快照 TTL 从「页面重建」起算改为「上次拉数据」起算；恢复快照后后台增量拉取、只把新条目前插（纯更新不打断滚动）；管理员发布成功立即刷新
- **探索库卡片精简** — 移除卡片右上角「可安装 / 用户分享」来源角标；顶栏「资源来源」筛选能力完整保留
- **KUNGAL 入口提速** — 并发请求共享同一结果（不再丢结果）、磁盘缓存改同步读、候选并行竞速：最坏路径约 **14s → 1.2s**，探索库列表还会预热前 30 条

### 🐛 修复

- **探索大厅相关话题底部整行黑色留白** — 「固定行高 + 向下取整」改为「行数由最小行高定、行高吃掉余量」，任何窗口高度都整份填满
- **探索大厅文档面板过高 / 窗口变窄时构建期崩溃** — `clamp` 上下限反序抛 `ArgumentError` 已修

### 已知问题

- 本版部分条目**尚未真机走查**：启动兼容性 8 项、启动程序推荐角标观感、KUNGAL 入口、删游戏回收站回执、数据扩批后的分类匣会社墙展示。
- `flutter test` 全量 **1485 通过 / 28 失败**，失败项均为既有问题（部分为 10-23 新增布局哨兵从未在 `flutter test` 下跑过）或上一任务未提交改动相关，**非本版引入**。
- 少量单测因本机 `ERROR_PIPE_BUSY (231)` 管道故障**未执行**，环境恢复后补跑。
- **云端安装**（应用目录内）的游戏删除仍是**永久删除**、不进回收站 —— 这类目录可由归档 / 重下重建，无需可恢复语义（有意）。
- 探索库数据侧仍有 5 类会社脏写法（`株式会社` / `AliceSoft(A社）` 等）与 55 个刻意不收的营销标签，需服务端清理，不影响客户端展示。
- 游戏标题图零密钥覆盖约七成（余下是 Steam 侧素材本身不存在）；大屏背景视频自动抓取默认关闭 —— 均为既有边界，本版未改。
