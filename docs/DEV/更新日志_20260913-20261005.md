## [v3.0.0] — 2026-10-05（待发布）

> **v3.0.0** 是继 v2.5.0 之后的**功能性大版本**，覆盖 2026-09-14 ~ 2026-10-05 的全部开发内容（共 332 次提交、535 个涉及文件）。

> 本次更新以「软件级游戏内手柄适配」「单文件导入·智能解压 + 安装中心」「游戏数据保存 / 云备份」「探索库资源来源扩展与元数据源接入」「账号体系本地化」「标签受控词表升级到九维」为六条主线，并对大屏模式 BPM、横幅/相册第二封面系统、系列体系、窗口体系与安装包体积做了系统性重构。

### ✨ 新增

- **软件级游戏内手柄适配** — 全新子系统：SDL3 输入层 + `SendInput` 注入，让原本只支持键盘鼠标的 Galgame 用手柄也能玩；支持**每游戏独立映射**、进程级生命周期单例、目录级前台守卫、**摇杆漂移免疫守卫**、假活自愈；内置编辑器 UI、首启询问与 SteamOS 通用预设（摇杆光标 / 滚轮）
- **大屏模式二级详情页（全屏整页）** — 取代原右侧滑出面板，对标 ubiquity 主题；内容主体化、按钮区 PN 化、声音拉杆、焦点保持
- **大屏模式自定义背景图 + OP 视频背景** — 支持自定义背景素材与 OP 视频背景播放，新增多素材背景管理窗口
- **大屏模式三段式入场动画** — 幕布合拢（150ms）→ 手柄轮廓描出 + 收尾柔光（540ms）→ 揭开落座（300ms），出场零动画，总时长 0.99 秒
- **单文件导入 · 智能解压（全新流程）** — 自动识别**多层嵌套**、**改后缀伪装包**（魔数嗅探）、**逐层密码**、**分卷压缩**、**网盘过审壳**（视频头 + 尾部拼接 zip）；五场景自动决策 + 隐式候选链 + 歧义选择窗 + 推荐引擎；支持 `.enc` 程序化解密、包内密码提取、磁盘预检、损坏明确报因
- **解压计划窗口（双层）** — ①设定（密码组 + 密码库管理）②后缀（内置改名链 + 自定义规则）；另设**实际解压区**（密码组填写 + 位置选择）；支持源包删除确认
- **密码组体系 + 记忆策略** — 密码去层级化：本次输入 → 预设组 → 历史组（签名去重 LRU 10）→ 密码库；**组为整体不可拆散**，分组整体记入历史；支持包内提取密码兜底
- **安装中心** — 统一任务中心承载本地压缩包解压；新增 `awaitingConfirmation` 相位与解压取消；新增**系统操作日志面板**（200 行环形缓冲，可收起）
- **游戏数据保存（存储状态）** — 存档「封装 / 解封」全链路：自动检测 + 面板自定义存档路径合并、**压缩前存档清单确认**、归档库（状态可视化 + 设置页分组）、打包 / 解包、回收站删除本体、**打包态双击引导解包**、解封替换询问（不再静默覆盖）、归档命名（游戏名_时间_状态）
- **云备份（Phase 5）** — 一期：Provider 接口 + WebDAV + DPAPI 凭据加密；二期：**S3 兼容源（AWS / R2 / OSS / COS / MinIO）** + 客户端加密（7z 加密外壳，云端物为标准 7z）+ **自动同步**（启动 / 24h / 7d 窗口，差集补传只增不删）+ 云端归档下载恢复
- **账号体系本地化 + 双态身份** — 本地优先，支持**本地游客**与**在线**双状态
- **注册邮箱验证码闭环 + 找回密码 OTP** — 兼容 163 / Outlook 邮件客户端
- **记住登录 + 会话续期** — DPAPI 加密凭证存储、token 过期**静默重登**、登录页「记住登录」勾选；根治「一段时间不用就掉线」
- **「我的喜欢」** — 【我的】tab 第三分段，分「作品 / 资源」两个子胶囊，可点击跳详情并直接取消喜欢
- **作品级点赞 + 资源级点赞** — `games.like_count` + `game_likes` + `resource_likes` 全链路，线上验收全绿
- **探索库资源来源扩展** — 资源来源数据层 + 卡片来源角标（可安装 / 用户分享）、探索详情页按 Figma 重设计、筛选栏 v2、顶栏 v3（两行布局）、【发布】三步向导 + 【我的】管理页、统一审核机制（编辑即重提）

- **标签受控词表九维** — 维度 8 → **9**（新增 adult 成人内容维，与 age 正交）；概念 **97 → 688**、别名键 **709 → 5253**（以 NextMoe 全量 3328 标签为基准语料扩充）；探索页标签覆盖率 28.5% → 73.9%（核心口径 98.2%）

- **窗口级圆角体系统一** — 13 种散落圆角收敛为四档（小对话框 12 / 大型模态面板 16 / 菜单气泡 8 / BPM 大屏 16~24），补齐 7 个直角窗口、9 处漏设
