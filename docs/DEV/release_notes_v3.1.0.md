# Chrono Tide v3.1.0

**发布日期：2026-10-17**　|　本版本覆盖 2026-10-08 ~ 2026-10-17 的全部开发内容（`3.0.6` 未单独发版，其全部内容已并入本版本）。

## 🌟 本版本亮点

- 🖋️ **游戏字体替换** — 接入自研 CTFontHook，在库页就能给 Galgame 换字体，无需手动改任何文件
- 🎨 **游戏标题图** — 主页 / 大屏大标题支持透明艺术字 Logo，Steam CDN + SteamGridDB 双源自动抓取
- 📺 **大屏背景视频自动抓取** — 自动探测 OP / ED / PV，弹窗确认后拉取，客厅模式更有氛围
- 🪟 **窗口体验治理** — 记住窗口位置与尺寸、小屏不再出血、拖出屏幕后有托盘逃生入口
- 🔞 **NSFW 分级判定 + UI 统一** — 误判与漏判双降，揭示角标全面可点
- ☁️ **OpenList 自动更新** — 对接服务配置与组件自动跟进服务器版本，不再需要手动点更新

## ✨ 新增

### 游戏字体替换（接入自研 CTFontHook）

- **首次启动引导**：首次启动游戏前弹窗询问是否安装字体程序（可勾选「不再提示」），自动识别启动程序并按其 32 / 64 位安装；「启动管理」弹窗内置字体替换区块（安装 / 恢复 / 字体设置）
- **字体选择器独立窗口**（对齐原工具面板设计）：搜索、字符集筛选（默认 / 中文 / 日文 / 繁体 / 韩文）、字体列表以**该字体自身渲染**、兼容设置九键（调用 / 映射转码 / 文字替换）、字形微调、中英日预览，两栏布局一屏展示无需滚动
- **全库字体管理器**：库页编辑模式新增「字体」按钮，游戏清单 + 勾选 + 批量安装 / 恢复，逐台串行执行、单台失败不阻断
- **纯本地不兼容清单**：命中已知不兼容游戏时黄色标注 + 说明，不阻断、不上报
- 开源致谢新增 CTFontHook 0.1.1（MIT）与 Microsoft Detours（MIT）

### 游戏标题图（透明 Logo）

- 主页 / 大屏主页的大标题支持透明艺术字 Logo 贴图，无图自动回退文字大标题（Playnite 同款）
- **Steam CDN + SteamGridDB 双源全自动抓取**，零密钥覆盖率约 70%（20 款抽样实测）
- SteamGridDB API Key 为**纯可选增强**（设置 → 网络与存储 → 大标题素材），不填不影响使用

### 大屏背景视频自动抓取（默认关闭）

- 大屏模式选中无视频的游戏时，可从 Steam 自动探测 OP / ED / PV 等相关视频（720p，约 30–45 MB，仅存本机）
- 素材分级选取：OP > ED > PV > 其它相关视频
- **探测 → 弹窗确认 → 拉取**：探到素材弹窗列出候选，由用户决定是否下载；无素材 / 失败一律静默不打扰；拒绝后 7 天内不再询问

### 窗口体验治理

- **窗口几何记忆**：记住上次位置 / 尺寸 / 最大化状态，Windows 缩放变化后按视觉尺寸恢复，显示器变更自动钳入工作区
- **启动尺寸自适应**：默认窗口尺寸按显示器工作区钳制，小屏 + 高缩放下窗口不再出血、标题栏三键不再够不到
- **托盘「重置窗口位置与尺寸」**：窗口被拖出屏幕 / 多显示器变更后的自救通道（大屏模式活跃时自动退出大屏再复位）
- 设置面板尺寸永不超过主窗口

### OpenList 对接服务自动更新

- 对接后的服务配置与组件自动跟进服务器版本：配置热更（服务在跑则挂起、停服后补上）+ 组件静默安装（等安全窗口才切换，不中断下载任务）
- 指纹比对 + 失败退避；未对接不产生任何下载

### 其他新增

- **探索免责协议改为「进入前弹窗 + 可拒绝」**，并下沉到首次探索行为前触发（进探索大厅不再弹）；拒绝即不进入、且下次仍会弹
- **添加页封面区相册**：上传 = 设为封面，删除 = 清除封面
- **探索库详情封面相册**（只读预览）
- **别名展示「一个名字一个框」**：探索详情 / 库详情弹窗 / CT 选择器三处统一
- **库页顶部栏 5 个按钮鼠标停留引导**（搜索 / 清空 / 管理 / 筛选 / 分类匣）

## 🔧 优化

- **NSFW 纯净模式分级判定（v2.6）** — 单一强度、双阈值 + explicit 硬门：误判（正常图被拦）与漏判（露点图未处理）双降，70 样本阈值实证 + 离线回放 FP=0 / FN=0；敏感图分级展示「NSFW」/「疑似」徽标，模糊强度完全一致（绝不因分级放行原图）
- **NSFW UI 统一（v2.7）** — 揭示角标移到左上角（不再被星级等角标遮挡）、全部图片默认开启揭示、图库「手动模糊」下沉为组件能力且独立于 NSFW 总闸
- **副标题 = 除主标题外全部别名**，详情页与探索库卡片改为多行完整展示
- **主页横幅**：背景用横幅、封面卡保持竖版（此前有横幅时封面卡会被切成横版）
- **大屏库页海报墙「先选中再操作」**：首击选中，再击进详情；双击则首击选中、二击启动
- **添加页封面预览缩小并随外框倾斜**，消除与下方截图区的重叠
- **导入板块顶栏选中态贴合边框**
- **库页【收藏夹】→【分类匣】**，与三视图面板及大屏同款按钮统一命名

## 🐛 修复

- **全新游戏首次启动不弹「启动管理」** — 导入时自动识别启动 exe 导致门禁被跳过；现首次启动（库页双击 / 主页入口）必弹启动管理弹窗，取消即不启动
- **打包软件携带个人数据** — 安装包此前可能携带开发者的手柄映射、解包密码、标签库改动等 8 项运行时数据，打包清理列表已全部堵漏
- **NSFW 揭示角标「看得见点不动」** — 探索库卡片 / 探索详情封面 / 大屏首页卡片三处装饰遮罩吞掉指针事件，现已修复并新增契约测试防回归
- **云端下载「取链接失败」静默无提示** — 解析直链失败此前全程无反应；现解析期间按钮转圈、失败在浮层内联红字且可原地重试
- **OpenList 网盘路径迁移适配 + 配置下发通道修复** — 夸克网盘游戏库迁移新路径后「获取链接失败」：服务端配置与下载链接数据修正（可解析率 91% → 97%），并修复配置下发通道从未生效的数组解析 bug
- **CT 探索库游戏名搜不到**：`突然恋人`、`Making Lovers` 等异体写法此前 0 命中，现可正确召回
- **单游戏手动导入横幅封面未写入**
- **「获取 Chrono Tide 下载」浮层版本信息不全**：版本号被挤掉、版本说明被裁切，现完整展示
