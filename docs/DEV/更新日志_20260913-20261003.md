## [v2.5.3] — 2026-10-03（待发布）

> **v2.5.3** 是 v2.5.0 之后的累计迭代版本，覆盖 2026-09-15 ~ 2026-10-03 的全部开发内容。本次更新以「游戏内手柄适配」「游戏数据保存 / 云备份」「探索库资源来源扩展」「账号体系本地化」「标签受控词表」为五条主线，并对大屏模式 BPM、导入链路、下载内核与安装包体积进行了系统性加固。

### ✨ 新增

- **游戏内手柄适配（软件级）** — 全新子系统：引入 SDL3 输入层 + `SendInput` 注入，让原本只支持键盘鼠标的 Galgame 可用手柄操作；支持**每游戏独立映射**、进程级生命周期单例、目录级前台守卫、**摇杆漂移免疫守卫**（固件级轴值卡死的软件防御）、假活自愈；内置编辑器 UI、首启询问与 SteamOS 通用预设（摇杆光标 / 滚轮）
- **大屏模式二级详情页（全屏整页）** — 取代原右侧滑出面板，对标 ubiquity 主题；内容主体化、按钮区 PN 化、声音拉杆、焦点保持；退出详情卡死与全屏最小化空操作已修复
- **大屏模式自定义背景图 + OP 视频背景** — 支持自定义背景素材与 OP 视频背景播放，新增多素材背景管理窗口
- **游戏数据保存（存储状态）** — 存档「封装 / 解封」全链路：自动检测 + 面板自定义存档路径合并、**压缩前存档清单确认**、归档库（状态可视化 + 设置页分组）、打包 / 解包、回收站删除本体、**打包态双击引导解包**、解封替换询问（不再静默覆盖）、归档命名（游戏名_时间_状态）
- **云备份（Phase 5）** — 一期：Provider 接口 + WebDAV + DPAPI 凭据加密；二期：**S3 兼容源（AWS / R2 / OSS / COS / MinIO）** + 客户端加密（7z 加密外壳，云端物为标准 7z）+ **自动同步**（启动 / 24h / 7d 窗口，差集补传只增不删）+ 云端归档下载恢复
- **账号体系本地化 + 双态身份** — 软件回归本地优先，支持**本地游客**与**在线**双状态
- **注册邮箱验证码闭环 + 找回密码 OTP** — 绕开后端内置缺陷自建验证码链路，兼容 163 / Outlook 邮件客户端
- **记住登录 + 会话续期** — 新增 DPAPI 加密凭证存储（`RememberMeStore`）、token 过期**静默重登**、登录页「记住登录」勾选与「快速登录」一键条；根治「一段时间不用就掉线」
- **「我的喜欢」** — 【我的】tab 第三分段，分「作品 / 资源」两个子胶囊，可点击跳详情并直接取消喜欢（乐观移除 + 失败回滚）
- **作品级点赞** — `games.like_count` + `game_likes` 全链路（服务端 + 客户端接线），线上验收 29/29 全绿
- **探索库资源来源扩展** — 资源来源数据层 + 卡片来源角标（可安装 / 用户分享 / 可安装 · N 分享）、探索详情页按 Figma 重设计、筛选栏 v2（内联控件 + 会社多选）、顶栏 v3（两行布局 / 资源来源筛选）、【发布】三步向导 + 【我的】管理页、统一审核机制（编辑即重提 + 已审资源删除）
- **标签受控词表** — 受控词表管理标签分类，维度 8 → **9**（新增 adult 成人内容维，与 age 正交）；概念 97 → **431**、别名键 709 → **3016**（VNDB 英文名对齐 + 内置日文表反向 + 组合式生成期展开）
- **分类匣三视图** — 原收藏夹改造为「标签库多选 + 会社墙关注」模块
- **会社别名词典归一化** — 会社词典扩充至 **97 家 / 330 键**，支持输入联想与 BPM / 详情页联动归一
- **系统提示聊天气泡** — 底部 SnackBar 收敛为与用户按钮对齐的系统提示气泡，支持自动收起
- **测试基建** — 联网集成测试打 `network` 标签 + 一键补跑脚本
- **全局图标换新** — 7 尺寸（16~256）多帧 ICO 无损合并，统一 exe / 任务栏 / 标题栏 / 系统托盘图标

### 🔧 优化

- **大屏模式 BPM（v3.9 → v3.22）** — 手柄全链路适配（多槽位 XInput / DirectInput 后端）、分层板块焦点系统（一级 / 二级 + 两级焦点状态机）、按钮规格统一（宽度 60）、声音优先级修正、文本输入与手柄模式热判定、自绘虚拟键盘、**主页键鼠两段式交互**（点击未选中卡片只落焦点，已选中才进详情；键盘连按两次 Enter 启动）
- **桌面 ⇄ 大屏切换**改「镜头推近」动画，替换原 250ms 纯淡入淡出
- **探索页顶栏 v3** — 两行布局 + 资源来源筛选 + 横幅板块退役；第二行五等分填满整行；标签面板按受控词表分组
- **添加页对齐 Figma 设计稿** — 封面 / 字段 / 卡片 / 模式栏共 25 处尺寸收紧，连体选项卡 + 卡片单行化
- **用户窗口 v2.5** — 对接按钮移至右上角图标行 + 整体紧凑化去空旷
- **对接入口轻量化** — 服务文案优化 + 6 连接下载提速
- **OpenList 半移植化** — 安装包体积 149 MB → **0**，改为应用内按需「对接」（更新不再解除用户对接）
- **下载内核** — 下载强度三档 + 全局限速；弱网（4G / 抖动）自适应分片，修复分片数失控与半开卡死
- **导入性能 / 稳定性 P0** — 消除大批量导入的卡死与崩溃路径（审计 7 条止血 + P1 两项）
- **媒体缓存治理** — 磁盘配额自动淘汰（最久未用优先）、截图限宽解码、解码缓存内存上限 64 MB + 阈值预警
- **安装包瘦身** — 体积由 92.7 MB **降至约 80 MB**：安装向导 2 张 BMP 转 PNG 像素级无损、工具库去双份分发、打包 Excludes 堵数据混入、死代码 16 文件 4503 行清理
- **超分预设重置** — 出厂预设由旧 11 档位收敛为与代码 `builtInPresets` 一致的 **15 档位**，修复运行时反复追加缺失预设导致的配置漂移
- **会社归一化** — 导入页输入联想接入入库表单 + 库页待审区 + 详情页联想
- **数据层加固** — 稳定主键 / 启动路径唯一源 / NSFW 缓存治理 / schema 版本化（批 1~4）
- **外观与主题** — 系统主题三卡竖排 → 横排；跟随系统主题；预设主题精简；GIF 动态背景播放；全局「减少动效」开关（动态背景可降级为静态首帧）
- **NAS / SMB 映射盘适配** — 映射网络驱动器全链路与启动期适配
- **桌面快捷方式开关全局化** — 默认关闭并迁入设置窗口（ADR-014）

### 🐛 修复

- 重复导入同一游戏导致库页 `Duplicate GlobalKey` 报错、丢渲染
- 智能导入排重：同名不同嵌套层级不再重复识别入库（IMP-22）
- exe 扫描关键字误匹配完整路径（目录名含 "Install Patch" 导致 0 个程序）
- 归档库钥匙统一：标题清洗名 → `game_id`（修复同名游戏共用归档根的串库隐患）
- 游戏数据层覆盖写入语义翻转、启动路径不唯一
- 验证码邮件正文空白（根因：后端内置 `authAlert` 登录提醒仅 html 单 part）+ 验证码冷却失效（goja 无法解析 `created` 文本）+ SMTP `tls` 语义配错
- 注册验证码超时 30s → 90s（发信接口偶发耗时 51.8s）
- `users` 集合 P0 越权；分享资源「打开链接」出口补登录 gate
- 同步方法内误用 `await` 导致编译失败（打包挂断根因）
- BPM v3.21 遗留 3 处编译错误（导入路径 / `calloc` / `SendInput` 签名）
- BPM 全屏下「最小化」空操作；退出二级详情卡死
- 手柄：按键零事件、`SDL_INIT_GAMEPAD` 常量错误（已连接显示未连接）、整体断连、假活、摇杆轴向反向、X·Y 卡死
- 探索页「我的」未登录 / 空列表提示在最小窗口纵向溢出 34px
- 探索页文档板块崩坏（`Wrap` 内 `InteractiveWrapper` 撑满整行）+ 上传弹窗设计外标线
- 浮层黄色双下划线（`AnimatedOverlay` 补透明 `Material`，一次性兜底 8 个浮层）
- 库详情窗口「元数据匹配」面板支持鼠标拖动 + 滚轮横向滚动
- 外观页「系统主题」三卡横排（`InteractiveWrapper` 在 `Wrap` 中的尺寸陷阱）
- 库页「存档备份」入口移植为详情页「备份」按钮；错误档驻留 30s → 15s
- 提示气泡未与用户按钮对齐
- 用户窗口 UID 行叠字 + 登录后浮层资料不刷新
- 收藏夹内排序串台（卡片 key 身份化，消除 State 串台）
- 下载分片数失控 + 半开「卡死」
