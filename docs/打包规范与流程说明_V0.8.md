## 二、代码层面强制规范

### 2.1 路径管理规范（不可违反！）

#### ❌ 禁止使用的写法

```dart
// 错误1: 使用相对路径
final exePath = './openlist/openlist.exe';
final downloadsDir = './downloads';

// 错误2: 使用硬编码绝对路径
final toolsDir = 'C:/Program Files/ChronoTide/_temp_tools';

// 错误3: 使用系统临时目录（会导致DLL找不到）
import 'package:path_provider/path_provider.dart';
final tempDir = await getTemporaryDirectory();
```

#### ✅ 强制使用的写法

```dart
import 'dart:io';
import 'package:path/path.dart' as path;
import '../core/path_helper.dart'; // 必须导入！

// 正确1: 通过 PathHelper 动态获取所有路径
final exeDir = PathHelper.exeDir;                    // exe所在目录
final openlistExePath = PathHelper.openlistExePath;  // {exeDir}/openlist/openlist.exe
final downloadsDir = PathHelper.downloadsDir;        // {exeDir}/downloads/
final gamesDir = PathHelper.gamesDir;                // {exeDir}/Games/
final toolsDir = PathHelper.toolsDir;                // {exeDir}/_temp_tools/
final rarLz4ExePath = PathHelper.rarLz4UnzipExePath; // {exeDir}/_temp_tools/rar_lz4_unzip.exe

// 正确2: 拼接自定义路径
final gameDir = PathHelper.getGameDir(gameTitle);    // {exeDir}/Games/{safeTitle}/
final downloadFile = PathHelper.getDownloadFilePath(fileName); // {exeDir}/downloads/{fileName}
```

## 三、固定打包流程（必须按顺序执行）

### 3.1 完整 PowerShell 脚本

```powershell
# ============================================================
# Chrono Tide V0.8 标准打包脚本
# 适用环境: Windows 10/11 + Flutter SDK
# 最后验证: 2026-05-02
# ============================================================

# 设置工作目录
Set-Location "D:\CT"

Write-Host "=========================================="
Write-Host "📦 Chrono Tide V0.8 标准打包流程"
Write-Host "=========================================="
Write-Host ""

# ==========================================
# 步骤 1: 清理旧构建
# ==========================================
Write-Host "[步骤 1/5] 清理旧构建..."
taskkill /F /IM chrono_tide.exe 2>$null
taskkill /F /IM openlist.exe 2>$null
taskkill /F /IM dart.exe 2>$null
flutter clean
if ($LASTEXITCODE -ne 0) { Write-Host "❌ flutter clean 失败"; exit 1 }
Write-Host "✅ 清理完成"
Write-Host ""

# ==========================================
# 步骤 2: 获取依赖
# ==========================================
Write-Host "[步骤 2/5] 获取依赖..."
flutter pub get
if ($LASTEXITCODE -ne 0) { Write-Host "❌ flutter pub get 失败"; exit 1 }
Write-Host "✅ 依赖就绪"
Write-Host ""

# ==========================================
# 步骤 3: 构建 Release 版本
# ==========================================
Write-Host "[步骤 3/5] 构建 Release 版本..."
flutter build windows --release
if ($LASTEXITCODE -ne 0) { Write-Host "❌ 构建失败"; exit 1 }

$exePath = "build\windows\x64\runner\Release\chrono_tide.exe"
$sizeMB = [math]::Round((Get-Item $exePath).Length / 1MB, 2)
Write-Host "✅ 构建成功: chrono_tide.exe (${sizeMB} MB)"
Write-Host ""

# ==========================================
# 步骤 4: 复制外置依赖文件
# ==========================================
Write-Host "[步骤 4/5] 复制外置依赖文件..."
$releaseDir = "build\windows\x64\runner\Release"

# 4.1 复制 OpenList 文件
Write-Host "  📁 复制 OpenList..."
if (Test-Path "$releaseDir\openlist") {
    Remove-Item "$releaseDir\openlist" -Recurse -Force
}
New-Item -ItemType Directory -Path "$releaseDir\openlist" -Force | Out-Null
Copy-Item "openlist\openlist.exe" "$releaseDir\openlist\" -Force
Copy-Item "openlist\data.zip" "$releaseDir\openlist\" -Force
xcopy /E /I /Y "openlist\data" "$releaseDir\openlist\data\" | Out-Null
Write-Host "     ✅ openlist/ (含 data/)"

# 4.2 复制解压工具
Write-Host "  🔧 复制解压工具..."
if (Test-Path "$releaseDir\_temp_tools") {
    Remove-Item "$releaseDir\_temp_tools" -Recurse -Force
}
New-Item -ItemType Directory -Path "$releaseDir\_temp_tools" -Force | Out-Null
Get-ChildItem "assets\tools" -File | ForEach-Object {
    Copy-Item $_.FullName "$releaseDir\_temp_tools\" -Force
}
Write-Host "     ✅ _temp_tools/ (7个文件)"

# 4.3 创建运行时目录
Write-Host "  📂 创建运行时目录..."
@('data', 'downloads', 'Games', 'logs') | ForEach-Object {
    $dirPath = Join-Path $releaseDir $_
    if (-not (Test-Path $dirPath)) {
        New-Item -ItemType Directory -Path $dirPath -Force | Out-Null
    }
}
Write-Host "     ✅ data/, downloads/, Games/, logs/"

# 统计信息
$totalFiles = (Get-ChildItem $releaseDir -Recurse -File).Count
$totalSizeMB = [math]::Round(
    (Get-ChildItem $releaseDir -Recurse -File | Measure-Object -Property Length -Sum).Sum / 1MB, 
    0
)
Write-Host ""
Write-Host "✅ 复制完成: $totalFiles 个文件, ~${totalSizeMB} MB"
Write-Host ""

# ==========================================
# 步骤 5: 验证完整性
# ==========================================
Write-Host "[步骤 5/5] 验证 Release 目录..."

$checks = @(
    @{ Name="chrono_tide.exe"; Path="$releaseDir\chrono_tide.exe" },
    @{ Name="openlist/openlist.exe"; Path="$releaseDir\openlist\openlist.exe" },
    @{ Name="openlist/data.zip"; Path="$releaseDir\openlist\data.zip" },
    @{ Name="rar_lz4_unzip.exe"; Path="$releaseDir\_temp_tools\rar_lz4_unzip.exe" },
    @{ Name="ark.x64.dll"; Path="$releaseDir\_temp_tools\ark.x64.dll" },
    @{ Name="openlist/data/"; Path="$releaseDir\openlist\data" },
    @{ Name="data/"; Path="$releaseDir\data" },
    @{ Name="downloads/"; Path="$releaseDir\downloads" },
    @{ Name="Games/"; Path="$releaseDir\Games" },
    @{ Name="logs/"; Path="$releaseDir\logs" }
)

$allPassed = $true
foreach ($check in $checks) {
    if (Test-Path $check.Path) {
        Write-Host "  ✅ $($check.Name)"
    } else {
        Write-Host "  ❌ $($check.Name) (缺失!)"
        $allPassed = $false
    }
}

Write-Host ""
if ($allPassed) {
    Write-Host "=========================================="
    Write-Host "🎉 打包完成！Release 版本已准备就绪"
    Write-Host "📍 输出目录: $releaseDir"
    Write-Host "=========================================="
} else {
    Write-Host "⚠️ 部分文件缺失，请检查上方列表"
    exit 1
}
```

## 五、常见问题与解决方案

### 5.1 `Failed to extract ucrtbase.dll` 错误

**症状**: 解压时报错，提示无法提取 ucrtbase.dll 或其他系统DLL

**原因**: 
- `rar_lz4_unzip.exe` 找不到依赖 DLL
- 工作目录未正确设置

**解决方案**:
1. 确认 `_temp_tools/` 目录包含所有必要文件：
   ```powershell
   Test-Path "Release\_temp_tools\rar_lz4_unzip.exe"
   Test-Path "Release\_temp_tools\ark.x64.dll"
   Test-Path "Release\_temp_tools\bdzshl.x64.dll"
   ```
2. 确认代码中设置了 `workingDirectory`:
   ```dart
   Process.run(exePath, args, 
       workingDirectory: PathHelper.toolsDir  // 必须设置！
   );
   ```

### 5.2 OpenList 服务启动失败

**症状**: 端口 5244 无响应，或程序卡在"正在连接OpenList..."

**原因**:
- `openlist/data/config.json` 缺失或损坏
- `openlist/data.db` 数据库文件不存在
- 端口被占用

**解决方案**:
1. 检查配置文件完整性：
   ```powershell
   Get-ChildItem "Release\openlist\data" -Recurse -File | Measure-Object | Select-Object Count
   # 应该 >= 12 个文件
   ```
2. 检查端口占用：
   ```powershell
   netstat -ano | findstr :5244
   # 如果有其他进程占用，先结束该进程
   taskkill /PID <进程ID> /F
   ```
3. 查看 OpenList 启动日志（控制台输出）：
   ```
   flutter: [OL-BOOT] 2/3 启动OpenList进程（端口5244）
   flutter: [OL-BOOT] ✅ 启动成功 | PID: xxxx
   ```

### 5.3 BOM 字符导致编译失败

**症状**: 编译报错 `error G90425F44: The non-ASCII space character U+FEFF...`

**原因**: 某些 .dart 文件开头包含 BOM（Byte Order Mark）字符

**解决方案**:
```powershell
# 检测并删除BOM字符
$file = "lib\pages\game_detail_page.dart"
$content = [System.IO.File]::ReadAllBytes($file)

# 检查前3字节是否是BOM (EF BB BF)
if ($content[0] -eq 0xEF -and $content[1] -eq 0xBB -and $content[2] -eq 0xBF) {
    $newContent = New-Object byte[] ($content.Length - 3)
    [Array]::Copy($content, 3, $newContent, 0, $content.Length - 3)

}
```

### 5.5 导入路径错误

**检查方法**: 在报错的文件顶部确认是否有上述 import。
